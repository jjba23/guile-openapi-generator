#+title: Todo example
#+options: toc:nil

A complete, runnable application built with guile-openapi-generator: one
OpenAPI specification, a generated tree, an in-memory store, four handlers and
a client.

* Run it

From this directory:

#+begin_src shell
./run.sh demo
#+end_src

That generates =gen/=, starts the API on =http://127.0.0.1:8080=, calls it with
the generated client, and stops the server.  The output is:

#+begin_example
2 todos before
created #3: Ship the app
fetched #3: Ship the app
delete returned 204
2 todos after
#+end_example

Guix is the only prerequisite; the script uses the manifest at the repository
root.

* The pieces

| File                     | What it is                                               |
|--------------------------+----------------------------------------------------------|
| =openapi.yaml=            | the specification: routes, request and response models   |
| =openapi-generator.yaml=  | the options this project always uses                     |
| =app.scm=                 | the server: store, one handler per operation, run-server |
| =client.scm=              | a program that calls the API with the generated client   |
| =run.sh=                  | generate, serve, call, demo                              |
| =gen/=                    | generated by the generator; do not edit it               |

* Step by step

** Generate

#+begin_src shell
./run.sh generate
#+end_src

or, without the script:

#+begin_src shell
guile -L ../../src -c '((@ (openapi-generator cli) main)
                        (list "generate" "--config" "openapi-generator.yaml"))'
#+end_src

=openapi-generator.yaml= says where the input is, where the output goes and what
the module is called:

#+begin_src yaml
input: openapi.yaml
output: gen
module: todo
controllers: vanilla
http: guile
#+end_src

The result is four files:

#+begin_example
gen/todo/models.scm        Todo and NewTodo records, validators, ->jso / jso->
gen/todo/controllers.scm   route table, dispatcher, guile-handler
gen/todo/client.scm        list-todos, create-todo, get-todo, delete-todo
gen/todo/README.org        a generated summary of the same tree
#+end_example

** Serve

#+begin_src shell
./run.sh server 8080
#+end_src

In =app.scm= the whole server is:

#+begin_src scheme
(parameterize ((api-handlers handlers))
  (run-server (guile-handler) 'http
              (list #:host "127.0.0.1" #:port 8080)))
#+end_src

=guile-handler= is generated with the portable controllers.  It converts the
request that Guile's web server hands over into an =<http-request>=, dispatches
it through the route table, and turns the =<http-response>= back into the
response and body =run-server= expects, including JSON serialisation.

A handler receives the request and an alist of the decoded arguments:

#+begin_src scheme
(define (get-todo-handler request arguments)
  (let ((todo (find-todo (cdr (assq 'id arguments)))))
    (if todo
        (ok (todo->jso todo))
        (not-found "No such todo"))))
#+end_src

Path, query, header and body values are already decoded and validated: a
=body= member holds a =NewTodo= record, an =id= member holds an integer.  A
handler returns a response built with =ok=, =created=, =no-content=,
=text-response=, =binary-response= or =error-response=.

** Call it

With the server running:

#+begin_src shell
curl http://127.0.0.1:8080/todos
curl -X POST http://127.0.0.1:8080/todos \
     -H 'Content-Type: application/json' \
     -d '{"title":"Ship the app"}'
curl http://127.0.0.1:8080/todos/3
curl -X DELETE http://127.0.0.1:8080/todos/3
#+end_src

or from Scheme:

#+begin_src shell
./run.sh client
#+end_src

#+begin_src scheme
(use-modules (ice-9 receive)
             (todo client)
             (todo models))

(define client (make-api-client))

(receive (todo response)
    (create-todo client
                 #:body (make-new-todo #:title "Ship the app" #:done #f))
  (format #t "created #~a~%" (todo-id todo)))
#+end_src

The client procedure returns two values: the decoded body and the
=<http-response>=.  Path parameters are keyword arguments too:
=(get-todo client #:id 3)=.

* Next steps

- **Add a route.** Add it to =openapi.yaml=, run =./run.sh generate=, and add a
  handler to =handlers= in =app.scm=.  The compiler and the generated README
  tell you the procedure and record names.
- **Use another framework.** Generate with =controllers: artanis= and replace
  =guile-handler= with the generated =register-routes!= adapter.
- **Use libcurl.** Set =http: curl= and regenerate; the operation procedures do
  not change, only the transport underneath them.
- **Vendor the runtime.** Add =self-contained: true= (or =--self-contained=) so
  the generated tree carries its own runtime and the application needs only
  Guile and guile-json.
- **Write a manifest.** Add =dependencies: guix= to get a =dependencies.scm=
  for =guix shell -m=.

See the top-level =README.org= for the full option list, content negotiation,
directional models and the rest of the generator.
