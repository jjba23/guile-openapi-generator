* By question

- *I have never used this.*  Read [[file:overview.org][Overview and features]], then
  [[file:quick-start.org][Quick start]].
- *I want to install it.*  [[file:install.org][Install]] lists every route and what each one
  needs.
- *I want to generate a client for someone else's API.*  [[file:quick-start.org][Quick start]]
  then [[file:generated-code.org::#authentication][Authentication]].
- *I have an existing server and want a specification.*
  [[file:spec.org][From routes to a specification]].
- *I want to change the generator itself.*  [[file:internals.org][Inside the generator]],
  then [[file:reference.org::#development][Development]].
- *Something behaves unexpectedly.*  [[file:generated-code.org::#when-something-goes-wrong][When something goes wrong]].
